# 策略收益合理性审查 20260704

## 审查结论

当前复跑结果可以证明策略在归档口径下可重复跑出高收益，但不能直接视为真实可交易预期。

主要原因：

1. `0` 滑点口径明显偏乐观。
2. 策略信号偏稀疏，历史 296 条信号、207 个买入日。
3. 规则使用 `buy_open_gap_qfq_max_pct`，属于买入日开盘后才知道的信息；如果定义为前一日晚间信号，则存在前视；如果定义为 09:30 开盘后动态过滤、09:31 下单，则不能再称为开盘前信号。
4. 交易可执行过滤使用 qfq gap 字段，不符合当前“执行过滤必须使用不复权真实价格”的硬边界。
5. 策略收益对滑点极敏感，说明真实成交质量会显著影响收益。

## 主要不真实风险

### 1. 买入日开盘过滤口径

`trading_rules.json` 中记录：

- `buy_open_gap_qfq_max_pct = 1.5`

生产信号中字段：

- `buy_open_gap_pct`

该字段是买入日开盘后才知道的信息。如果策略声称在前一晚生成完整买入名单，则该字段不能用于筛选；如果策略允许 09:30 开盘后过滤、09:31 下单，则需要把信号定义为“开盘后动态可执行信号”，并接受成交滑点和排队风险。

### 2. qfq 字段用于执行过滤

当前项目硬规则要求：

- 因子、模型、技术指标可以用明确 qfq 字段；
- 涨跌停、真实成交、开盘可买、滑点、交易过滤必须使用不复权真实价格。

该策略用 `buy_open_gap_qfq_max_pct` 做买入过滤，不符合当前生产执行边界。

### 3. 0 滑点展示过于乐观

策略累计成交额约 `9.06` 亿，交易成本非常关键。0.30%-0.40% 滑点下，年化从 `402.35%` 降到 `213.82%` / `171.51%`，说明真实执行会显著削弱收益。

### 4. 信号偏稀疏

历史全量只有 `296` 条信号、`207` 个买入日。收益指标高，但样本覆盖不宽，策略更像“稀疏强事件策略”，不应当按稳定日频宽策略理解。

## 建议口径

1. 不再展示 `0` 滑点作为主收益口径。
2. 默认展示至少使用 `0.30%` 或真实成交估计滑点。
3. 重新生成一版严格 raw 执行过滤信号：
   - `buy_open_gap_raw_pct`
   - `buy_open_raw`
   - `buy_pre_close_raw`
   - `open_limit_up_raw`
4. 将策略定义为两种之一：
   - 前一日晚间信号：不能使用买入日开盘 gap 过滤；
   - 开盘后动态信号：允许使用开盘价，但成交价格不能再按无滑点开盘成交假设。
5. 生产准入前必须补一版 raw 执行字段重建和滑点后掘金复跑。
