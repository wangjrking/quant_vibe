# 正式5D10D融合优选策略发布说明

## 当前结论

`prod_formal_5d10d_best_v20260621` 已作为当前唯一 L5 production 策略发布。发布候选为 `best_noncal_avgpred205_rw2121201919`，选择依据是在非日历、非行业限制候选中，满足 `Sharpe >= 3` 的最高年化收益版本。

本次发布只做 L5 标准链路配置和归档收口，没有生成新的正式交易信号，没有运行新的掘金回测。

## 策略规则

输入只允许使用模型智能体批准的 formal L4 资产：

- `executable_5d_open_return_l4_formal_20260620.json`
- `executable_10d_open_return_l4_formal_20260617.json`

评分使用 10D 为主、5D 为辅的融合池。主池采用 `10D rank 0.9 + 5D rank 0.1`，弱日补位池采用 `10D rank 0.6 + 5D rank 0.4`。当主池候选数不超过 1 时启用弱日补位。

交易过滤：

- 不买北交所。
- 不买 ST、退市股。
- 不买当前涨停股。
- 次日开盘涨停则跳过买入。
- 不使用月份、日期、行业过滤。

仓位规则：

- 最多 5 只。
- 名次目标仓位为 `21% / 21% / 20% / 19% / 19%`。
- 单票最高 `21%`。
- 启用账户回撤缩放，但不主动缩放已有持仓。

卖出规则：

- 基础持有 7 个交易日。
- 最长持有 10 个交易日。
- 持有满 3 个交易日后启用评分卖出。
- 每日最多卖出 1 只。
- 评分续持门槛为买入评分的 `1.02`。
