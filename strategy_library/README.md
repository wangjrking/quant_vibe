# Strategy Library

策略库分为投产策略和探索策略。

## 投产策略规则

- 必须有唯一 `strategy_id`、中文名称、版本号和状态。
- 必须归档预测标签、训练窗口、模型参数、因子筛选方式、因子清单、选股规则、买卖规则和回测效果。
- 必须记录证据文件来源，包括信号文件、验证日志、训练折摘要和最新信号快照。
- 不允许覆盖旧版本；策略升级必须新增版本并更新 `registry.json`。
- 只有 `registry.json` 中 `production.current` 指向的策略可以作为默认投产策略。

## 探索策略规则

- 参数搜索、临时回测、未完成验证和未归档版本均属于探索策略。
- 探索策略不能被每日自动交易脚本默认调用。
- 探索策略进入投产前，必须补齐投产策略归档。
