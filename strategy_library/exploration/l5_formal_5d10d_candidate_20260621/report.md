# formal L4 5D+10D 非日历 L5 研究候选

## 当前结论

本轮继续只使用标准链路已发布的 `formal L4` 5D 和 10D 预测资产，不使用 1D，不使用旧 `odb.db.stock_predict_data_*` 默认预测表。所有有效效果口径以掘金回测为准。

当前合法 L5 研究候选更新为 `best_noncal_avgpred205`。该候选在掘金回测中：

- 年化收益率：`254.11%`
- Sharpe：`3.0066`
- 平均持仓率：`58.89%`
- 80% 以上持仓覆盖：`17.27%`
- 最大回撤：`23.60%`

结论：年化收益和 Sharpe 已达到目标；持仓率未达到 80% 偏好目标。该版本仍是 L5 研究候选，不是正式投产策略，不能直接进入生产或交易执行。

## 方法约束

此前做过“排除月份/具体日期/亏损区间”等实验。该类规则属于数据窥探和过拟合风险，不能作为有效策略规则进入 L5 候选。

- 当前候选未采用任何排除月份、具体日期或事后亏损区间过滤。
- 当前候选未采用行业限制。
- 本轮只允许模型分数、市值、成交额、换手率、可交易性和账户风险控制等非日历规则。
- 继续保留约束：不买北交所，不买 ST/退市，不买当前涨停，次日开盘涨停跳过买入。

## 策略规则

- 输入资产：最新 `approved_for_l5` formal L4 5D 与 10D 预测资产。
- 基础信号：沿用弱日换池信号，普通日使用 `rank_10d90_5d10` 主池与 `rank_10d60_5d40` 补仓池。
- 弱日换池：当基础信号日 `primary_count <= 1` 时，补仓池成交额提高到 `>= 20000`，换手率提高到 `>= 0.5`。
- 强信号集中：只保留基础信号日 `primary_count >= 2` 且日内 `rank <= 5` 的买入候选。
- 非日历质量过滤：要求候选股票 formal L4 10D 原始预测 `pred_10d >= 0`。
- 新增信号日质量门槛：在上述过滤之后，要求当日剩余候选的平均 `pred_prob >= 2.05`。
- 持仓：最多 5 只，按日内 rank 近等权配置：Top1 `20.7%`、Top2 `20.7%`、Top3 `20.0%`、Top4 `19.3%`、Top5 `19.3%`，现金缓冲 `0.99`。
- 持有：默认 7 个交易日；若分数保持强势，最多延长到 10 个交易日。
- 退出：开启每日分数退出，`score_exit_entry_ratio = 1.00`，至少持有 3 日后触发，每日最多卖出 1 只；持仓延续阈值 `score_continue_entry_ratio = 1.02`。
- 风控：启用账户回撤缩放，回撤 `12%` 触发软降仓，回撤 `22%` 触发硬降仓，恢复阈值 `5%`，不强制重调已有持仓。

## 加大仓位测试

本轮补充测试了三类提高暴露的方法：提高单票目标仓位、增加 `rank_max/max_positions`、放宽账户回撤缩放或持有期。结果显示，平均持仓率可以略微提高，但 Sharpe 和回撤会明显恶化。

通过年化 `200%` 且 Sharpe `3` 的组合里，平均持仓率最高的是 `best_noncal_avgpred205_rw2121201919`：

- 年化收益率：`257.09%`
- Sharpe：`3.0045`
- 平均持仓率：`59.16%`
- 最大回撤：`23.81%`

更激进的高仓位组合表现如下：

- `best_noncal_avgpred205_rw2221201918`：平均持仓率 `59.60%`，年化 `254.55%`，Sharpe `2.9669`
- `best_noncal_avgpred205_rw2523211917`：平均持仓率 `61.23%`，年化 `222.61%`，Sharpe `2.6445`
- `best_noncal_avgpred205_rank7`：平均持仓率 `61.63%`，年化 `135.17%`，Sharpe `2.2786`
- `best_noncal_avgpred205_rank8`：平均持仓率 `62.19%`，年化 `102.83%`，Sharpe `2.0543`

结论：在当前模型评分和交易约束下，继续强行加仓会降低风险调整收益；主候选暂不替换。若目标从“Sharpe 过 3”改为“尽量高仓位”，需要单独定义新的优化目标。

## 目标 80% 持仓测试

本轮进一步尝试把平均持仓率推向 `80%`。测试方法包括：放宽信号日质量门槛到 `avg_pred >= 2.00/1.95/1.90/1.85`，扩大 `rank_max/max_positions` 到 8、10、12，提高单日目标仓位，并关闭或放松回撤缩放。

结果显示，当前标准链路评分下无法在保持收益质量的同时达到 80% 平均持仓。最高持仓率组合如下：

- `target80_avgpred195_rank10_t12`：平均持仓率 `70.15%`，年化 `82.44%`，Sharpe `1.6433`，最大回撤 `26.13%`
- `target80_avgpred190_rank10_t12`：平均持仓率 `70.15%`，年化 `82.44%`，Sharpe `1.6433`，最大回撤 `26.13%`
- `target80_noavg_rank10_t12`：平均持仓率 `70.07%`，年化 `81.14%`，Sharpe `1.6212`，最大回撤 `26.13%`
- `target80_noavg_rank12_t10`：平均持仓率 `68.51%`，年化 `139.57%`，Sharpe `2.1703`，最大回撤 `25.44%`
- `target80_top5_t2523211917_noeqdd`：平均持仓率 `63.63%`，年化 `234.39%`，Sharpe `2.6641`，最大回撤 `28.12%`

结论：要把持仓推到接近 70%，必须买入更弱、更靠后的候选，收益和 Sharpe 均显著下降。当前模型信号不支持 80% 平均持仓目标；主候选继续保留 `best_noncal_avgpred205`。

## 三支以内集中测试

本轮补充测试了“只买 3 支以内”的集中持仓方案，均保留 `post_filter_avg_pred_min >= 2.05` 的质量门槛，并继续使用掘金回测口径。结果显示，减少持股数量没有改善风险调整收益。

- `best_noncal_avgpred205_top3_403020`：Top3，目标仓位约 `40%/30%/20%`，年化 `141.95%`，Sharpe `1.9692`，平均持仓率 `54.52%`
- `best_noncal_avgpred205_top2_4949`：Top2，目标仓位约 `49%/49%`，年化 `129.52%`，Sharpe `1.5459`，平均持仓率 `59.17%`
